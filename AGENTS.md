# Website change rules

Read docs/website-decisions.md before changing this website. Start from the latest GitHub main tree, compare changes made by Mugo or others, and preserve them. Never replace current code using an older preview or transfer pack.

For payment work, test the public Payments entry WITHOUT URL credentials, the private payment entry, application submission, payment-link recovery, and Stripe return/cancellation. A successful API test alone does not prove the visible user journey works. State exactly what was tested and whether changes are local, on GitHub, or deployed on Namecheap. Never claim inbox delivery from provider acceptance.

Use targeted diffs. Preserve unrelated branding, forms, simulation, services and admissions changes. Record material decisions below. Do not publish live changes without user approval.
